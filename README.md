# Playwright Naukri Automation

This project automates the Naukri profile headline update flow using:
- Playwright
- JavaScript
- Page Object Model (POM)

## Test Flow
1. Navigate to Naukri
2. Login with valid credentials
3. Open profile section
4. Edit resume headline
5. Save changes
6. Validate success message

## Tech Stack
- Playwright
- JavaScript
- Node.js

## Run Project
npm install
npx playwright test
